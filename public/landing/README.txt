Photos d'écoliers pour la landing page NotesCam
===============================================

Déposez ici vos propres photos (libres de droits ou dont vous détenez les droits)
aux noms EXACTS ci-dessous. Tant qu'un fichier est absent, un dégradé décoratif
avec emoji s'affiche automatiquement (la page n'est jamais "cassée").

Format conseillé : JPG, paysage, 1200×800 px environ, < 300 Ko (compressées).

Fichiers attendus :
- ecolier-hero.jpg   → petite vignette ronde dans la section d'accueil (idéal : portrait d'un élève souriant)
- ecoliers-1.jpg     → galerie (grande tuile verticale) — élèves du primaire
- ecoliers-2.jpg     → galerie — en classe
- ecoliers-3.jpg     → galerie — travail de groupe
- ecoliers-4.jpg     → galerie (grande tuile verticale) — fierté de réussir
- ecoliers-5.jpg     → galerie — cour de récréation
- ecoliers-6.jpg     → galerie — sourires d'élèves

Astuce : privilégiez des photos d'élèves d'Afrique centrale (Cameroun / Guinée
Équatoriale) pour refléter votre public. Veillez à disposer des autorisations
nécessaires (droit à l'image) avant publication.
